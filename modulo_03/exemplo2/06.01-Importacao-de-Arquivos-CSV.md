# 06.01 – Importação de Arquivos CSV

---

# Introdução

Grande parte dos dados utilizados em auditorias tributárias não está armazenada diretamente em bancos de dados relacionais. Informações provenientes de sistemas corporativos, contribuintes, órgãos reguladores e bases públicas geralmente são disponibilizadas em arquivos de texto, planilhas eletrônicas ou arquivos CSV.

O formato CSV (*Comma-Separated Values*) é amplamente utilizado por sua simplicidade, compatibilidade entre diferentes sistemas e facilidade de processamento. No contexto da auditoria fiscal, é comum receber arquivos contendo informações sobre produtos, notas fiscais, cadastros e tabelas auxiliares que precisam ser integrados ao banco de dados antes da realização das análises.

Neste capítulo, serão apresentados os principais métodos para importar arquivos CSV para o SQL Server, utilizando tanto os recursos gráficos do SQL Server Management Studio (SSMS) quanto comandos SQL como o `BULK INSERT`.

---

# Objetivos

Ao final deste capítulo o aluno será capaz de:

- compreender o papel dos arquivos CSV em processos de integração de dados;
- identificar a estrutura de arquivos delimitados;
- criar um banco de dados para armazenamento das informações;
- criar tabelas de apoio para importação;
- importar arquivos utilizando o Assistente do SSMS;
- importar arquivos utilizando `BULK INSERT`;
- validar a integridade dos dados importados.

---

# Cenário

Neste exercício serão utilizados três conjuntos de dados:

1. **Registro 0200 da Escrituração Fiscal Digital (SPED Fiscal)** – tabela já existente no banco de dados.
2. **Arquivo `anexo_5_sefaz.csv`** – contendo informações oficiais de NCM, CEST, MVA e legislação.
3. **Arquivo `abcfarma.csv`** – contendo dados regulatórios e comerciais de medicamentos.

O objetivo é importar os dois arquivos CSV para o SQL Server e, posteriormente, relacioná-los com a tabela do SPED Fiscal por meio do campo **NCM**.

# Estrutura dos Arquivos CSV

## Arquivo 1 – anexo_5_sefaz.csv

Delimitador: `|`

Principais campos:

| Campo | Descrição |
|--------|-----------|
| CEST | Código Especificador da Substituição Tributária |

| Vigencia_inicial | Início da vigência |
| Vigencia_final | Fim da vigência |

# Importação pelo SQL Server Management Studio (SSMS)

O SQL Server Management Studio disponibiliza um assistente gráfico para importação de arquivos de texto.

1. Clique com o botão direito sobre o banco de dados.
2. Selecione **Tasks**.
3. Clique em **Import Flat File**.
4. Escolha o arquivo `anexo_5_sefaz.csv`.
5. Verifique se o delimitador (`|`) foi identificado corretamente.
6. Confirme os tipos de dados sugeridos.
7. Finalize a importação.

Repita o procedimento para o arquivo `abcfarma.csv`.

---

# Importação utilizando BULK INSERT

### Importação do Anexo V

```sql
BULK INSERT dbo.TB_ANEXO5_SEFAZ
FROM 'C:\Importacao\anexo_5_sefaz.csv'
WITH
(
    FIRSTROW = 2,
    FIELDTERMINATOR = '|',
    ROWTERMINATOR = '\n',
    CODEPAGE = '65001'
);
```

### Importação da ABCFARMA

```sql
BULK INSERT dbo.TB_ABCFARMA
FROM 'C:\Importacao\abcfarma.csv'
WITH
(
    FIRSTROW = 2,
    FIELDTERMINATOR = '|',
    ROWTERMINATOR = '\n',
    CODEPAGE = '65001'
);
```

# Boas Práticas

- Verifique sempre o delimitador utilizado pelo arquivo.
- Utilize codificação UTF-8 (`CODEPAGE = '65001'`) para evitar problemas com acentuação.
- Importe inicialmente para tabelas de apoio (*staging tables*) antes de integrar os dados às tabelas principais.
- Valide a quantidade de registros importados.
- Confira se campos numéricos e datas foram interpretados corretamente.
