# 7.17 OPENQUERY

## Conceito

O `OPENQUERY` executa uma consulta diretamente no servidor remoto e retorna apenas o resultado.

```sql
SELECT *
FROM OPENQUERY
(
 OracleERP,
 'SELECT CODIGO,NOME FROM CLIENTE'
);
```

Também pode ser utilizado em inserções.

```sql
INSERT INTO Cliente
SELECT *
FROM OPENQUERY
(
 OracleERP,
 'SELECT CODIGO,NOME FROM CLIENTE'
);
```

## Quando utilizar

- Oracle → SQL Server
- PostgreSQL → SQL Server
- MySQL → SQL Server
- SQL Server → SQL Server

## Vantagens

- Melhor desempenho que consultas distribuídas em muitos cenários;
- Processamento realizado no servidor remoto.

## Exercício

Importe todos os fornecedores de um banco Oracle utilizando OPENQUERY.
