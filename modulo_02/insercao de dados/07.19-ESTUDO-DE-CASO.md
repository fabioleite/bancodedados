# 7.19 Estudo de Caso

# Integração de Dados de uma Universidade

## Cenário

Uma universidade possui:

- Sistema Acadêmico
- Sistema Financeiro
- Ambiente de Business Intelligence

Todos armazenam dados em bancos distintos.

## Problema

Todos os dias os dados precisam ser consolidados para geração de indicadores.

## Solução

1. Linked Server conecta o sistema acadêmico.
2. OPENQUERY importa dados do ERP Oracle.
3. BULK INSERT carrega arquivos CSV enviados pelos polos.
4. MERGE sincroniza cadastros.
5. INSERT OUTPUT registra auditoria.
6. SSIS automatiza todo o fluxo.

## Resultado

- Processo automatizado.
- Redução do tempo de carga.
- Eliminação de retrabalho.
- Base analítica atualizada diariamente.

## Questões para discussão

1. Qual método seria mais adequado para milhões de registros?
2. Quando utilizar MERGE em vez de INSERT SELECT?
3. Em quais situações o Import Wizard é suficiente?
