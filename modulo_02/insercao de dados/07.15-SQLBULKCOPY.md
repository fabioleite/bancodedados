# 7.15 SqlBulkCopy (.NET)

## Conceito
`SqlBulkCopy` é uma classe do .NET utilizada para inserir grandes volumes de registros no SQL Server.

## Exemplo

```csharp
using(SqlBulkCopy bulk = new SqlBulkCopy(conn))
{
    bulk.DestinationTableName = "Aluno";
    bulk.WriteToServer(dataTable);
}
```

## Funcionamento
1. Dados carregados em um DataTable.
2. SqlBulkCopy envia os registros em lote.
3. SQL Server grava diretamente na tabela.

## Aplicações
- APIs REST.
- Sistemas ERP.
- Importadores de planilhas.
- Integração de dados.

## Vantagens
- Excelente desempenho.
- Pouco consumo de memória.
- Integração nativa com .NET.
