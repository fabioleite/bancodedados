# 5.4 CREATE TABLE

## Conceito
Define a estrutura física de uma tabela.

```sql
CREATE TABLE Aluno
(
 IdAluno INT PRIMARY KEY,
 Nome VARCHAR(100) NOT NULL,
 DataNascimento DATE,
 Email VARCHAR(150) UNIQUE,
 Ativo BIT DEFAULT 1
);
```
