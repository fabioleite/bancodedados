# 06.06 -- Desafios de ETL e Enriquecimento de Dados

## Objetivos

Construir uma base consolidada para auditoria tributária.

## SELECT INTO

``` sql
SELECT *
INTO dbo.TB_AUDITORIA_PRODUTOS
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO;
```

## INSERT INTO

``` sql
INSERT INTO dbo.TB_AUDITORIA_PRODUTOS(...)
SELECT ...
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO;
```

## Atualização incremental

Utilize MERGE ou INSERT/UPDATE para carregar apenas novos registros.

## Views

Crie uma VIEW consolidando SPED, Anexo V e ABCFARMA.

## Materialized Views

No SQL Server utilize tabelas de consolidação ou Indexed Views quando
aplicável.

## Índices

Crie índices sobre: - REG0200_COD_NCM - REG0200_CEST - NCM_SH - NCM

## Performance

-   Evite SELECT \*
-   Utilize filtros seletivos.
-   Atualize estatísticas.
-   Analise planos de execução.
-   Indexe colunas utilizadas nos JOINs.

## Desafio Final

Construa uma tabela consolidada contendo contribuinte, produto, NCM,
CEST oficial, MVA, laboratório, ANVISA, PMC e indicadores de divergência
para alimentar dashboards de auditoria.
