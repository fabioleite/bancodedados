# Módulo 05 – Modelagem Física no SQL Server

Este módulo reúne os principais conceitos e práticas para a implementação física de um banco de dados no Microsoft SQL Server. Os arquivos aqui presentes abordam desde a criação do banco e das estruturas básicas até temas avançados como índices, performance, convenções de projeto e estudos de caso.

## Objetivos
- Compreender o papel da modelagem física na implementação de bancos de dados.
- Criar bancos, schemas e tabelas de forma correta e organizada.
- Definir tipos de dados, constraints e relacionamentos de maneira consistente.
- Aplicar boas práticas de desempenho, segurança e manutenção.
