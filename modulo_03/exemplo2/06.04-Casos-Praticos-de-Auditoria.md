# 06.04 -- Casos Práticos de Auditoria

## Caso 1 -- Produto sem NCM

**Objetivo:** identificar produtos sem classificação fiscal.

``` sql
SELECT REG0200_COD_ITEM,REG0200_DESCR_ITEM
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO
WHERE REG0200_COD_NCM IS NULL;
```

**Análise:** solicitar correção cadastral.

## Caso 2 -- CEST incorreto

Compare o CEST declarado com o oficial do Anexo V.

``` sql
SELECT E.REG0200_COD_ITEM,E.REG0200_CEST,A.CEST
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO E
JOIN dbo.TB_ANEXO5_SEFAZ A ON E.REG0200_COD_NCM=A.NCM_SH
WHERE CAST(E.REG0200_CEST AS VARCHAR(20))<>A.CEST;
```

## Caso 4 -- Medicamento não encontrado

## Caso 5 -- Produto sujeito à ST

Identificar produtos com MVA cadastrada no Anexo V.

## Caso 6 -- Seleção de contribuintes

Construir ranking de contribuintes com maior quantidade de
inconsistências e priorizar fiscalização.

## Resumo

Os casos apresentados simulam situações reais de auditoria tributária
utilizando cruzamento entre SPED, Anexo V e ABCFARMA.
