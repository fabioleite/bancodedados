# 06.03 -- Consultas de Auditoria Tributária

> Módulo 06 -- Importação e Cruzamento de Dados para Auditoria
> Tributária

## Objetivos

Ao final deste capítulo o aluno será capaz de:

-   identificar inconsistências cadastrais na EFD ICMS/IPI;
-   validar NCM, CEST e alíquota de ICMS utilizando bases oficiais;
-   cruzar informações do SPED Fiscal com o Anexo V da SEFAZ e a
    ABCFARMA;
-   produzir indicadores para apoio à seleção de contribuintes.

## Introdução

Após importar e integrar as bases de dados, o auditor passa à etapa de
análise. O objetivo é localizar inconsistências que possam indicar erros
cadastrais, classificação fiscal incorreta, aplicação inadequada da
Substituição Tributária ou oportunidades para fiscalização.

As consultas apresentadas neste capítulo utilizam as tabelas:

-   `fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO`
-   `dbo.TB_ANEXO5_SEFAZ`
-   `dbo.TB_ABCFARMA`

------------------------------------------------------------------------

## 1. Produtos sem NCM

``` sql
SELECT
    REG0200_COD_ITEM,
    REG0200_DESCR_ITEM
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO
WHERE REG0200_COD_NCM IS NULL
   OR LTRIM(RTRIM(REG0200_COD_NCM))='';
```

Esta consulta identifica os produtos que não possuem NCM informado, o que pode indicar uma classificação fiscal incompleta ou ausente.

------------------------------------------------------------------------

## 2. Produtos sem CEST

``` sql
SELECT
    REG0200_COD_ITEM,
    REG0200_DESCR_ITEM,
    REG0200_COD_NCM
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO
WHERE REG0200_CEST IS NULL;
```

Esta consulta localiza os produtos que não possuem CEST preenchido, permitindo detectar itens que podem estar sujeitos à Substituição Tributária sem a devida identificação.

------------------------------------------------------------------------

## 3. NCM inexistente na tabela oficial

``` sql
SELECT
    E.REG0200_COD_ITEM,
    E.REG0200_DESCR_ITEM,
    E.REG0200_COD_NCM
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO E
LEFT JOIN dbo.TB_ANEXO5_SEFAZ A
ON E.REG0200_COD_NCM=A.NCM_SH
WHERE A.NCM_SH IS NULL;
```

Esta consulta mostra os NCMs declarados que não existem na base oficial do Anexo V, sinalizando possível erro de classificação fiscal.

------------------------------------------------------------------------

## 4. CEST divergente

``` sql
SELECT
    E.REG0200_DESCR_ITEM,
    E.REG0200_CEST AS CEST_DECLARADO,
    A.CEST AS CEST_OFICIAL
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO E
INNER JOIN dbo.TB_ANEXO5_SEFAZ A
ON E.REG0200_COD_NCM=A.NCM_SH
WHERE CAST(E.REG0200_CEST AS VARCHAR(20))<>A.CEST;
```

Esta consulta compara o CEST informado no SPED com o CEST oficial da tabela de referência, destacando divergências de classificação.

------------------------------------------------------------------------

## 5. Alíquota divergente

``` sql
SELECT
    E.REG0200_DESCR_ITEM,
    E.REG0200_ALIQ_ICMS AS ALIQ_DECLARADA,
    A.Aliq_Interna AS ALIQ_OFICIAL
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO E
INNER JOIN dbo.TB_ANEXO5_SEFAZ A
ON E.REG0200_COD_NCM=A.NCM_SH
WHERE E.REG0200_ALIQ_ICMS<>A.Aliq_Interna;
```

Esta consulta aponta produtos cuja alíquota de ICMS declarada diverge da alíquota oficial cadastrada na base do Anexo V.

------------------------------------------------------------------------

## 6. Produtos fora da vigência

``` sql
SELECT
    NCM_SH,
    DESCRICAO,
    Vigencia_final
FROM dbo.TB_ANEXO5_SEFAZ
WHERE Vigencia_final<GETDATE();
```

Esta consulta lista os registros da tabela oficial que já estão fora da vigência, permitindo identificar regras fiscais que não devem mais ser consideradas válidas.

------------------------------------------------------------------------

## 7. Medicamentos encontrados na ABCFARMA

``` sql
SELECT
    E.REG0200_DESCR_ITEM,
    B.NOME,
    B.LABORATORIO,
    B.REGISTRO_ANVISA,
    B.PMC
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO E
INNER JOIN dbo.TB_ABCFARMA B
ON E.REG0200_COD_NCM=B.NCM;
```

Esta consulta cruza os produtos da EFD com a base da ABCFARMA para encontrar medicamentos cadastrados na base complementar.

------------------------------------------------------------------------

## 8. Produtos não encontrados na ABCFARMA

``` sql
SELECT
    E.REG0200_COD_ITEM,
    E.REG0200_DESCR_ITEM
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO E
LEFT JOIN dbo.TB_ABCFARMA B
ON E.REG0200_COD_NCM=B.NCM
WHERE B.NCM IS NULL;
```

Esta consulta mostra os produtos que não foram encontrados na base da ABCFARMA, o que pode indicar ausência de cadastro ou divergência de classificação.

------------------------------------------------------------------------

## 9. Produtos sujeitos à Substituição Tributária

``` sql
SELECT
    NCM_SH,
    CEST,
    MVA_Original
FROM dbo.TB_ANEXO5_SEFAZ
WHERE MVA_Original IS NOT NULL;
```

Esta consulta lista os NCMs que possuem MVA informado, indicando os itens que podem estar sujeitos à Substituição Tributária.

------------------------------------------------------------------------

## 10. Painel da Auditoria

``` sql
SELECT
    COUNT(*) AS TOTAL_PRODUTOS,
    COUNT(DISTINCT REG0200_COD_NCM) AS TOTAL_NCM,
    COUNT(DISTINCT REG0200_CEST) AS TOTAL_CEST,
    COUNT(DISTINCT REG0_IE) AS TOTAL_CONTRIBUINTES
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO;
```

Esta consulta fornece um resumo geral da base, apresentando quantidade de produtos, NCMs, CESTs e contribuintes distintos para apoiar o painel de auditoria.

## Fluxo de Auditoria

``` text
SPED Fiscal
     │
     ├── JOIN → Anexo V
     ├── JOIN → ABCFARMA
     ▼
Base Consolidada
     ▼
Regras de Auditoria
     ▼
Relatórios e Seleção de Contribuintes
```

## Boas práticas

-   Validar NCM antes de analisar CEST.
-   Comparar sempre os dados declarados com bases oficiais.
-   Criar índices sobre NCM e CEST.
-   Registrar a origem dos dados utilizados.

## Resumo

As consultas deste capítulo representam exemplos de regras utilizadas em
auditorias tributárias para localizar inconsistências cadastrais,
validar enquadramentos fiscais e apoiar a seleção de contribuintes para
fiscalização.
