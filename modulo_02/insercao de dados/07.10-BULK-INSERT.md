# 7.10 BULK INSERT

## Conceito
Importa grandes volumes de dados diretamente de arquivos texto ou CSV.

```sql
BULK INSERT Cliente
FROM 'C:\Importacao\clientes.csv'
WITH(
 FIRSTROW=2,
 FIELDTERMINATOR=',',
 ROWTERMINATOR='\n'
);
```

## Aplicação
Migração de sistemas, Data Warehouse, ETL e cargas periódicas.

## Vantagens
- Alto desempenho.
- Milhões de registros em poucos minutos.

## Boas práticas
- Validar encoding do arquivo.
- Executar em transações quando apropriado.
- Registrar erros de importação.
