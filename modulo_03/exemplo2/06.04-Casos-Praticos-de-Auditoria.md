# 06.04 -- Casos Práticos de Auditoria

## Caso 1 -- Produto sem NCM

**Objetivo:** identificar produtos sem classificação fiscal.

```sql
SELECT REG0200_COD_ITEM,REG0200_DESCR_ITEM
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO
WHERE REG0200_COD_NCM IS NULL;
```

**Análise:** solicitar correção cadastral.

## Caso 2 -- CEST incorreto

Compare o CEST declarado com o oficial do Anexo V.

```sql
SELECT E.REG0200_COD_ITEM,E.REG0200_CEST,A.CEST
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO E
JOIN dbo.TB_ANEXO5_SEFAZ A ON E.REG0200_COD_NCM=A.NCM_SH
WHERE CAST(E.REG0200_CEST AS VARCHAR(20))<>A.CEST;
```

## Caso 3 -- Alíquota divergente

Validar alíquota declarada versus oficial.

```sql
SELECT
	E.REG0200_COD_ITEM,
	E.REG0200_DESCR_ITEM,
	E.REG0200_COD_NCM,
	E.REG0200_ALIQ_ICMS AS ALIQ_DECLARADA,
	A.Aliq_Interna AS ALIQ_OFICIAL,
	A.Legislacao
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO AS E
INNER JOIN dbo.TB_ANEXO5_SEFAZ AS A
	ON E.REG0200_COD_NCM = A.NCM_SH
WHERE E.REG0200_ALIQ_ICMS IS NOT NULL
  AND A.Aliq_Interna IS NOT NULL
  AND E.REG0200_ALIQ_ICMS <> A.Aliq_Interna;
```

**Análise:** verificar a vigência da regra no Anexo V antes de concluir pela divergência.

## Caso 4 -- Medicamento não encontrado

Cruzar SPED × ABCFARMA para localizar medicamentos sem correspondência.

```sql
SELECT
	E.REG0200_COD_ITEM,
	E.REG0200_DESCR_ITEM,
	E.REG0200_COD_NCM,
	E.REG0200_COD_BARRA,
	E.REG0200_CEST
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO AS E
LEFT JOIN dbo.TB_ABCFARMA AS B
	ON E.REG0200_COD_NCM = B.NCM
WHERE E.REG0200_COD_NCM LIKE '30%'
  AND B.NCM IS NULL;
```

**Análise:** a ausência na ABCFARMA pode indicar NCM incorreto, produto sem registro sanitário ou desatualização da base complementar.

## Caso 5 -- Produto sujeito à ST

Identificar produtos com MVA cadastrada no Anexo V.

```sql
SELECT DISTINCT
	E.REG0200_COD_ITEM,
	E.REG0200_DESCR_ITEM,
	E.REG0200_COD_NCM,
	A.CEST,
	A.MVA_Original,
	A.Aliq_Interna,
	A.Legislacao
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO AS E
INNER JOIN dbo.TB_ANEXO5_SEFAZ AS A
	ON E.REG0200_COD_NCM = A.NCM_SH
WHERE A.MVA_Original IS NOT NULL;
```

**Análise:** confirmar a vigência, a operação e a condição do destinatário antes de caracterizar obrigação de ST.

## Caso 6 -- Seleção de contribuintes

Construir ranking de contribuintes com maior quantidade de
inconsistências e priorizar fiscalização.

```sql
SELECT TOP (20)
	E.REG0_IE AS INSCRICAO_ESTADUAL,
	COUNT(*) AS TOTAL_ITENS_ANALISADOS,
	SUM(CASE WHEN E.REG0200_COD_NCM IS NULL
				  OR LTRIM(RTRIM(E.REG0200_COD_NCM)) = ''
			 THEN 1 ELSE 0 END) AS ITENS_SEM_NCM,
	SUM(CASE WHEN A.NCM_SH IS NOT NULL
				  AND E.REG0200_CEST IS NOT NULL
				  AND CAST(E.REG0200_CEST AS VARCHAR(20)) <> A.CEST
			 THEN 1 ELSE 0 END) AS CEST_DIVERGENTE,
	SUM(CASE WHEN A.NCM_SH IS NOT NULL
				  AND E.REG0200_ALIQ_ICMS IS NOT NULL
				  AND A.Aliq_Interna IS NOT NULL
				  AND E.REG0200_ALIQ_ICMS <> A.Aliq_Interna
			 THEN 1 ELSE 0 END) AS ALIQUOTA_DIVERGENTE,
	SUM(CASE WHEN E.REG0200_COD_NCM IS NULL
				  OR LTRIM(RTRIM(E.REG0200_COD_NCM)) = ''
				  OR (A.NCM_SH IS NOT NULL
					  AND E.REG0200_CEST IS NOT NULL
					  AND CAST(E.REG0200_CEST AS VARCHAR(20)) <> A.CEST)
				  OR (A.NCM_SH IS NOT NULL
					  AND E.REG0200_ALIQ_ICMS IS NOT NULL
					  AND A.Aliq_Interna IS NOT NULL
					  AND E.REG0200_ALIQ_ICMS <> A.Aliq_Interna)
			 THEN 1 ELSE 0 END) AS TOTAL_INCONSISTENCIAS
FROM fisc.TB_418_PR_EFD_REGISTRO_0200_IDENTIFICACAO_ITEM_PRODUTO_SERVICO AS E
LEFT JOIN dbo.TB_ANEXO5_SEFAZ AS A
	ON E.REG0200_COD_NCM = A.NCM_SH
GROUP BY E.REG0_IE
ORDER BY TOTAL_INCONSISTENCIAS DESC,
		 TOTAL_ITENS_ANALISADOS DESC;
```

**Análise:** o ranking apoia a seleção, mas os itens devem ser validados contra a vigência da norma e o contexto da operação antes de qualquer procedimento fiscal.

## Resumo

Os casos apresentados simulam situações reais de auditoria tributária
utilizando cruzamento entre SPED, Anexo V e ABCFARMA.
