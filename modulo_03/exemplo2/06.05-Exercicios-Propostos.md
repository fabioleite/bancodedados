# 06.05 -- Exercícios Propostos

## Exercícios Práticos

1.  Importe os dois arquivos CSV.
2.  Conte os registros importados.
3.  Liste os produtos sem NCM.
4.  Liste os produtos sem CEST.
5.  Localize NCM inexistentes no Anexo V.
6.  Identifique CEST divergentes.
7.  Compare as alíquotas de ICMS.
8.  Liste produtos sujeitos à ST.
9.  Cruze SPED com ABCFARMA.
10. Liste medicamentos sem correspondência.
11. Conte produtos por NCM.
12. Conte medicamentos por laboratório.
13. Crie uma VIEW consolidada.
14. Gere um painel estatístico.
15. Escreva uma consulta para selecionar contribuintes com maior risco
    fiscal.

## Questões Discursivas

-   Explique a finalidade do NCM.
-   Qual a função do CEST?

relatório de auditoria.
